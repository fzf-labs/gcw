# Issue Body Template

Use this template for the issue body:

```markdown
## What to build

A concise description of the end-to-end behavior or outcome. Describe the complete slice, not a layer-by-layer implementation checklist.

## Acceptance criteria

- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

## Notes

Important constraints, decisions, source references, or unknowns. Omit this section if there are no useful notes.

## Blocked by

None - can start immediately

Or list the blocking issue, decision, credential, or review if one exists.
```
