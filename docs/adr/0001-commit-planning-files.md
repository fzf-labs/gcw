# Commit Planning Files

GCW commits planning files to the issue branch under `.gcw/issues/<issue-id>/`, pushes them to the Git hosting platform, links them from the issue progress comment, and allows them to appear in the review request diff and be merged to the base branch. This keeps agent planning, findings, progress, and review context available through stable remote links instead of leaving the workflow's working memory hidden in chat or local-only files, accepting that the repository will retain GCW collaboration metadata as part of its project history.
